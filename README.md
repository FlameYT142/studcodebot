# 🤖 УГОЛОК СТУДЕНТА — @studcodebot

Бот для заказа разработки Telegram-ботов с ИИ-консультантом.

## 🚀 Возможности
- 🤖 Заказ ботов (описание, бюджет, сроки)
- 🧠 ИИ-консультант на DeepSeek-V4-Pro
- 🕐 Время по Братску (UTC+8)

## 🔐 Переменные окружения
| Ключ | Значение |
| :--- | :--- |
| BOT_TOKEN | Токен от @BotFather |
| KEY_ID | Key ID из Cloud.ru |
| SECRET | Secret из Cloud.ru |
| ADMIN_CHAT_ID | ID чата админов |
